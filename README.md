# InventoryPro

InventoryPro is a full-stack Inventory & Order Management System built with Java, Spring Boot, React, TypeScript, PostgreSQL, and REST APIs.

The application helps businesses manage products, inventory levels, customers, orders, and reorder alerts through a responsive dashboard.

## Features

- Product inventory management
- Product CRUD operations
- Customer management
- Order creation and tracking
- Automatic inventory reduction when orders are placed
- Low-stock and reorder alerts
- Search and filtering
- PostgreSQL relational database
- Custom JPA/JPQL database queries
- Responsive React dashboard
- REST API architecture
- Spring Security configuration
- Input validation

## Tech Stack

### Backend

- Java 21
- Spring Boot
- Spring Data JPA
- Hibernate
- Spring Security
- PostgreSQL
- Maven

### Frontend

- React
- TypeScript
- Vite
- CSS
